# Contributing Guidelines

Thanks for checking out the Ξχ Physics Simulation Framework!

---

## 🚨 Bug Reports

If you encounter a bug, please include:

1. Operating system and Python version (`python --version`)
2. Simulation config or flags used (e.g., `--gamma_c 0.7`)
3. Full traceback or output logs (if possible)

---

## 🌟 Feature Requests

We welcome all ideas! Open an issue and include:

- What the feature does
- Why it matters to your research
- If possible: a sketch, code snippet, or paper reference

---

## 🧠 Contributing Code

Fork this repo, make your changes, and submit a pull request.

Make sure to:

- Use `black` to format your code
- Write docstrings for new functions
- Add your name to the contributors section of the README
