
# Contributing to the Ξ–χ Framework

Thank you for considering contributing to this project!

## Ways to Contribute
- Report bugs using the Issues tab
- Propose theoretical extensions (use Theory Suggestion template)
- Share observational datasets or simulation outputs
- Help improve Dash UI or documentation

## Guidelines
- Fork the repo and create a feature branch
- Open a PR when ready, referencing an issue or proposal
- Use clear commit messages
- Cite equations and theory sources when relevant
