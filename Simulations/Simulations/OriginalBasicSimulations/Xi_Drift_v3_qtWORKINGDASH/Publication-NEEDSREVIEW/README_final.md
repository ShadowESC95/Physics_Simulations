## Features
- 🔬 Horndeski scalar-tensor evolution (Model 5)
- 🧪 Falsifiability tests vs Planck, pulsars, atomic clocks
- 📈 Dash app for visual simulation control
- 🐳 Docker + Colab + Binder deployment
